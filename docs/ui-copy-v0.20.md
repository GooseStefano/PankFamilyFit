# UI copy — v0.20.2

Это список основных пользовательских фраз для спокойного домашнего тона. Для обоих профилей используем «ты», «мы» и «давай», без официальных «Вы» и «Ваш». Общие фразы остаются нейтральными по полу; персональные учитывают профиль. Ошибки безопасности, прав доступа и диагностика остаются точными.
