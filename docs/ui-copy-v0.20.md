# UI copy — v0.20.0

Это список основных пользовательских фраз для спокойного домашнего тона. Он не является заданием на массовую замену: строки со статусом «обсудить» остаются в интерфейсе, пока не будет согласована формулировка.

| Где используется | Текущий текст | Более домашний вариант | Статус |
| --- | --- | --- | --- |
| Приветствие профиля | `Привет, Вика` | `Привет, Викуся` | заменить |
| Переключатель профиля | `Вика` | `Викуся` | заменить |
| Послание для Дани | `Послание от Вики` | `Послание от Викуси` | заменить |
| Настройки посланий | `Фразы для Вики` | `Фразы для Викуси` | заменить |
| Пустое послание | `Сегодня послания нет` | `Сегодня пока нет послания` | обсудить |
| Чеклист | `Небольшой чеклист` | `На сегодня — самое важное` | обсудить |
| Добавление еды | `Добавить еду` | `Записать, что было в еде` | обсудить |
| Комментарий дня | `Комментарий дня` | `Заметка для себя` | обсудить |
| Загрузка | `Загружаем семейный дневник…` | `Открываем ваш дневник…` | обсудить |
| Offline-статус | `Оффлайн · последний снимок` | `Оффлайн · показываем сохранённое` | обсудить |
| Отчёт | `Итог недели` | `Как прошла неделя` | обсудить |
| Ошибки и безопасность | Текущие предупреждения об офлайне, правах и PIN | Оставить точными и нейтральными | оставить |
