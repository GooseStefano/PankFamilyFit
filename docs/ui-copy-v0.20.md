# UI copy — v0.20.1

Это список основных пользовательских фраз для спокойного домашнего тона. Он не является заданием на массовую замену: строки со статусом «обсудить» остаются в интерфейсе, пока не будет согласована формулировка.

| Где используется | Текущий текст | Более домашний вариант | Статус |
| --- | --- | --- | --- |
| Приветствие профиля | `Привет, Вика` | `Привет, Викуся` | заменить — выполнено |
| Переключатель профиля | `Вика` | `Викуся` | заменить — выполнено |
| Послание для Дани | `Послание от Вики` | `Послание от Викуси` | заменить — выполнено |
| Настройки посланий | `Фразы для Вики` | `Фразы для Викуси` | заменить — выполнено |
| Пустое послание | `Сегодня послания нет` | `Сегодня пока без послания` | заменить — выполнено |
| Чеклист | `Небольшой чеклист` | `На сегодня` | заменить — выполнено |
| Пустой приём пищи | `В … пока нет еды` | `Пока ничего не добавлено` | заменить — выполнено |
| Комментарий дня | `Комментарий к дню` | `Заметка на день` | заменить — выполнено |
| Подсказка заметки | `Как прошёл день? Самочувствие, сон…` | `Что хочется запомнить?` | заменить — выполнено |
| Загрузка | `Загружаем семейный дневник…` | `Открываем ваш дневник…` | заменить — выполнено |
| Offline-статус | `Оффлайн · последний снимок` | `Оффлайн · показываем сохранённое` | заменить — выполнено |
| Отчёт | `Итог недели` | `Как прошла неделя` | заменить — выполнено |
| Вес | `Динамика веса` | `Как меняется вес` | заменить — выполнено |
| Цель веса | `Цель веса` | `Цель по весу` | заменить — выполнено |
| Быстрый выбор продуктов | `Частые` / `Избранное` | `Часто добавляем` / `Любимое` | заменить — выполнено |
| Добавление еды | `Добавить еду` | `Добавить еду` | оставить |
| Настройки привычек | `Привычки` | `Полезные мелочи` | обсудить |
| Шаблоны | `Шаблоны еды` | `Готовые варианты` | обсудить |
| Ошибки и безопасность | Текущие предупреждения об офлайне, правах и PIN | Оставить точными и нейтральными | оставить |
