# Pank Family Fit v0.2

Мобильный дневник КБЖУ для Дани и Вики. Реализован как React/Vite-приложение с локальным демо-хранилищем; SQL-схема Supabase находится в `supabase/schema.sql`.

## Запуск

```bash
npm install
npm run dev
```

Данные демо-режима сохраняются в `localStorage`, включая запомненный вход. PIN-коды в клиентском коде представлены только SHA-256 хэшами.

## Что входит

- PIN-вход и запоминание устройства;
- роли admin/member и переключение профиля у Дани;
- дневник по четырём приёмам пищи;
- расчёт и неизменяемый снимок КБЖУ;
- редактирование, перенос по дате/приёму и удаление записей;
- история дней и комментарии;
- база продуктов, поиск, категории, любимые, архивирование;
- создание продукта/блюда;
- история целей по дате;
- недельный отчёт по КБЖУ с планом, фактом, разницей и средними значениями;
- оценка недели и детализация по дням с учётом истории целей;
- интерфейс Graphite & Pistachio в mobile-first контейнере;
- подтверждения опасных действий, пустые состояния и короткие уведомления.

## Недельный отчёт v0.2

В разделе «История» доступны два режима: недельный отчёт и список дней. Неделя считается с понедельника по воскресенье. План каждого дня формируется из цели КБЖУ, которая действовала именно на эту дату, поэтому изменение цели в середине недели корректно влияет только на последующие дни.

Даня может переключать отчёт между своим профилем и профилем Вики. Вика видит только собственные данные.

### Чеклист проверки недельного отчёта

- [ ] По умолчанию открывается текущая неделя с корректным диапазоном дат
- [ ] Предыдущая неделя открывается по кнопке влево
- [ ] Из прошлой недели можно перейти вперёд и вернуться кнопкой «К текущей неделе»
- [ ] Неделя начинается в понедельник и заканчивается в воскресенье
- [ ] План, факт и разница рассчитаны для Ккал / Белков / Жиров / Углеводов
- [ ] Среднее КБЖУ рассчитано по семи календарным дням
- [ ] Дефицит калорий выделен фисташковым, профицит — оранжевым, отклонение до 5% — нейтрально
- [ ] Текстовая оценка соответствует порогам калорий, белков, жиров и углеводов
- [ ] Каждый день показывает факт, цель, разницу и статус
- [ ] Нажатие на день открывает дневник на выбранной дате
- [ ] Неделя без еды показывает «За эту неделю пока нет записей»
- [ ] Пустые дни внутри недели отображаются и участвуют в среднем
- [ ] При изменении цели с определённой даты дни недели используют разные действующие цели
- [ ] Даня переключает отчёт между собой и Викой
- [ ] Вика видит только собственный отчёт и не видит переключатель профилей
- [ ] Режим «Дни» сохраняет прежний список истории
- [ ] Отчёт помещается на телефоне шириной 375 px и не скрывается нижней навигацией

## Supabase

Примените `supabase/schema.sql` в SQL Editor. Для безопасной production-версии PIN нельзя проверять запросом к таблице из браузера: добавьте Edge Function для проверки PIN и выдачи короткоживущего JWT, затем RLS-политики по `user_id` и `role`. До настройки backend приложение намеренно работает в локальном режиме.
